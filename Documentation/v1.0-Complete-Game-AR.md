# LegendsStyleRPG v1.0 — اللعبة الكاملة (دليل شامل)

لعبة RPG ثلاثية الأبعاد للموبايل بنمط **Legends Reborn / GrandQuest**:
مدينة رئيسية ثلاثية الأبعاد بمبانٍ وظيفية، استدعاء أبطال بنظام شفافة، قصة من 180 مرحلة،
نقابة كاملة بقاعة ثلاثية الأبعاد، ساحة PVP، برج، زنازين، منجم، وحوش، تقنيات،
مهام يومية، متاجر، أحداث، اقتصاد كامل — وكل شيء محفوظ ويعمل فعليًا.

> **كل زر في هذه اللعبة يؤدي وظيفة حقيقية.** لا توجد أزرار ديكورية ولا محتوى وهمي.
>
> **v1.1 — قرار تصميم نهائي:** القتال بنمط Legends Reborn بالكامل — كل الأبطال
> يتحركون ويهاجمون تلقائيًا بالذكاء الاصطناعي (تشكيل أمامي/خلفي + مطاردة أقرب عدو)،
> واللاعب يتحكم فقط في: الـ Ultimate بضغط البورتريه الجاهز (توهج عند امتلاء الطاقة)،
> AUTO، السرعة x1/x2/x3، الإيقاف المؤقت، عداد وقت المعركة، وأزرار الكاميرا الجانبية.

## 2. البناء السريع (APK في 4 خطوات)

1. ثبّت **Unity Hub** ثم **Unity 2022.3.55f1** مع وحدة **Android Build Support**
   (مع OpenJDK وAndroid SDK & Tools).
2. افتح مجلد `GameClient/` عبر Unity Hub — سيُنشأ مشهد `Boot.unity` تلقائيًا
   عند أول فتح (EditorBootstrap) وتُسجّل في Build Settings.
3. من قائمة Unity: **Legends RPG → Build → Build Android APK**
   — يُكتب الملف في `Builds/Android/LegendsRPG-v1.0.0.apk`.
4. انقل الـ APK إلى هاتفك وثبّته (فعّل «مصادر غير معروفة» إن طُلب).

> أول تشغيل يمنحك: كايل البطل الملتهب + طقم معدات كامل + 2,500 ذهب + 600 ألماس.

## 3. خريطة اللعب السريعة

| أين | ماذا تجد |
|---|---|
| وسط المدينة | صندوق AFK (اضغط للاستلام) والنافورة |
| حول الساحة | 10 مبانٍ: استدعاء/نقابة/ساحة/زنازين/بوابة قارة/ترتيب/منجم/وحوش/سوق/حدادة |
| الشريط العلوي | اسمك ومستواك وVIP وقوتك + الذهب والألماس |
| الشريط السفلي | مهام/دردشة/تقنيات/متجر/توقيع/حدادة/أبطال/حقيبة |
| يسار الشاشة | توقيع 8 أيام، العروض، الحدث الأسبوعي، التاجر المتجول |
| يمين الشاشة | الإعدادات (جرافيكس وصوت)، الملف الشخصي، الترتيب |

## 4. حلقة التقدم

1. **اسحب أبطالًا** (نافورة الاستدعاء) — المكرر يتحول شظايا.
2. **طوّر فريقك** (شاشة البطل: مستوى + Ascension + معدات + حدادة).
3. **اقتلع القصة** (12 فصلًا) وارفع نجومك لمكافآت الألماس.
4. **اطرد دخلك**: صندوق AFK + المنجم + القافلة النقابية تعمل بالوقت الحقيقي.
5. **نافس**: الساحة PVP للترتيب، البرج للصعوبة، بوابة القارة للنهاية.
6. **انمُ مع المجتمع**: نقابة + دردشة + أحداث أسبوعية.

## 5. التقنيات

- **العميل**: Unity 2022.3.55f1 LTS / C# / uGUI مبنية بالكود بالكامل (بلا Assets خارجية)
  — كل المشاهد تُبنى وقت التشغيل من GameRoot.
- **الحفظ**: JSON محلي (Schema v3) على `Application.persistentDataPath`
  بنفس شكل مزامنة الخادم (حسابات + حفظ سحابي + منع التراجع عبر FastAPI).
- **الخادم**: Python 3.11 / FastAPI / PBKDF2 / SQLite (راجع `Documentation/ServerSetup.md`).
- **الأداء**: هدف 60fps، 4 مستويات جرافيكس حقيقية، تجميع VFX بالمواد المشتركة.

## 6. الغموض المعروف

- أعضاء النقابة والخصوم في الدردشة والترتيب لاعبون محاكون محليًا (لا سيرفر واقعي
  في هذه النسخة) — كل منطق النقابة نفسه (الدم المشترك، القافلة، الأمنيات) حقيقي
  ومحفوظ وسيصبح متعدد اللاعبين عند توصيل Backend بنفس الواجهات.
- نصوص الواجهة إنجليزية لتطابق لقطات المرجع؛ توثيق المشروع كامل بالعربية.
