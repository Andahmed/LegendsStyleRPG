# LegendsStyleRPG — لعبة RPG Fantasy ثلاثية الأبعاد للموبايل

مشروع لعبة RPG ثلاثية الأبعاد لنظام Android مستوحى من أسلوب Legends Reborn، بعالم وشخصيات وأنظمة أصلية. هذا المستودع يحتوي التسليم الكامل: عميل Unity + Backend Python + التوثيق + اختبارات.

## هيكل التسليم

```
LegendsStyleRPG/
├── GameClient/        ← مشروع Unity Android (افتحه بـ Unity Hub)
│   └── Assets/Scripts/Items/  ← نظام المعدات: أسلحة/دروع/تعاويذ/أجنحة/مرافقين/مواكب
├── Backend/           ← خدمة Python/FastAPI (حسابات، حفظ سحابي، اقتصاد لاحقًا)
├── Deployment/        ← Docker + إعدادات التطوير/الإنتاج
├── Tests/             ← تقارير الاختبار ولقطات الشاشة
├── Builds/Android/    ← تُكتب هنا مخرجات APK
└── Documentation/     ← Architecture / Installation / ServerSetup / TestingGuide
```

## الإصدار الحالي

- **v1.1.0-auto-combat** — نمط القتال النهائي (قرار تصميم): كل الأبطال يتحركون ويهاجمون
  تلقائيًا بالذكاء الاصطناعي (تشكيل أمامي/خلفي + مطاردة أقرب عدو)، الـ Ultimate بضغط
  البورتريه الجاهز (توهج عند امتلاء الطاقة)، AUTO لإطلاق المهارات تلقائيًا، سرعة x1/x2/x3،
  إيقاف مؤقت، عداد وقت المعركة، أزرار كاميرا (زاوية/إرجاع) بدون تدوير بالسحب،
  شريط دم فوق كل وحدة، وإشعارات Kill streak. أُزيل نهائيًا: عصا التحكم، زر الهجوم
  اليدوي، وتبديل البطل النشط.
- **v1.0.0-complete-game** — اللعبة الكاملة بنمط Legends Reborn / GrandQuest:
  - **مدينة 3D** بعشرة مبانٍ وظيفية قابلة للنقر + صندوق AFK مركزي بتراكم حقيقي.
  - **استدعاء أبطال** بشفافة (Pity) و10x وبطاقات ندرة وأنيميشن Skip.
  - **تفاصيل بطل** بموديل ثلاثي الأبعاد حي + Ascension بالشظايا حتى 6★.
  - **قصة 12 فصلًا × 15 مرحلة** بنظام 3 نجوم، **برج** بصعوبات، **PVP Arena** بمواسم،
    **بوابة القارة** للمحتوى النهائي، **زنازين** ذهب/خبرة.
  - **نقابة كاملة** بقاعة ثلاثية الأبعاد: صيد زعيم بدم مشترك، قافلة، حرب،
    تقنيات، هدايا يومية، وجدار أمنيات يتحقق فعلًا.
  - **اقتصاد كامل**: ذهب/ألماس/VIP/قوة قتال + مهام يومية + متجر يومي + تاجر متجول
    + توقيع 8 أيام + حدث أسبوعي + تقنيات + حدادة + منجم + وحوش مروّضة.
  - شريط لاعب علوي وشريط تنقل سفلي (8 أزرار تعمل كلها) وعمود أنشطة.
  - قتال تلقائي كامل: كل الأبطال بالذكاء الاصطناعي + Ultimate بضغط البورتريه + AUTO
    + سرعة x1/x2/x3 + إيقاف مؤقت + شريط HP الزعيم + أشرطة دم فوق الوحدات
    + كشف الهزيمة وإعادة المحاولة.
  - حفظ Schema v3 شامل لكل الأنظمة، جاهز للمزامنة مع خادم FastAPI المرفق.
  - **62 بطلًا** (7 عناصر × 8 أبطال مولّدين بمعادلات + 6 أبطال مصممين يدويًا) بتدرجات ندرة خمسة Common→Mythic.
  - **نظام معدات كامل**: 235 قطعة (40 سلاح + 40 درع + 40 تعويذة + 40 جناح + 35 مرافق + 40 موكب) × 5 ندرات، 6 خانات ارتداء لكل بطل، تطبيق إحصائيات حقيقي، أجنحة مرفرفة ومرافق طائر كمنظر مرئي، غنائم عشوائية عند إنهاء الطوابق، وحفظ كامل في ملف الحفظ (schema v2 متوافق خلفيًا).
  - **9 وحوش عادية + 2 زعيم** تغطي العناصر السبعة كلها في موجات البرج.
- **v0.1.0-prototype** — Prototype 0.1 كامل + أساسات 0.3 (فريق/AI كامل/مهارات تلقائية) و0.4 و0.5 (برج 4×200 طابق).
- إصدار Unity الموثق: **2022.3.55f1** — Minimum API 23، Target API 34.
- الحسابات والاقتصاد والـ Online: مبنيان كخدمة Backend مختبرة؛ الربط من داخل اللعبة في مراحل لاحقة كما في خطة التكليف.
