Drop UI PNG files here (any sub-folder). They are picked up automatically.
Slots / accepted names:
  button  : button, buttonLong_brown, buttonLong_beige, buttonLong_blue, buttonSquare_brown
  panel   : panel, panel_brown, panel_beige, panel_blue
  inset   : panel_inset, panelInset_brown, panelInset_beige, panelInset_blue
Add _b16 to a file name to set a 16px 9-slice border (default 12px for panel*/button*).
