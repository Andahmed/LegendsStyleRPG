# TestReports / تقارير الاختبار

ضع هنا تقارير الاختبار لكل إصدار بالصيغة:

```
TestReport_v<رقم الإصدار>_<تاريخ>.md
```

**قالب إلزامي لكل تقرير:**

```markdown
# تقرير اختبار الإصدار vX.Y — التاريخ
## بيئة الاختبار
- جهاز 1: (الموديل، Android version، RAM) — النتيجة: FPS المتوسط/الأدنى، RAM الذروة، ملاحظات حرارة
- جهاز 2: ...
- إصدار Unity: ... | Build size: ... MB
## ما تم اختباره
(انسخ بنود ورقة المرحلة من ملف Excel مع الحالة والنتيجة)
## ما نجح
## ما لم يكتمل (إلزامي الذكر بصراحة)
## أخطاء معروفة
## مرفقات
- لقطات شاشة / فيديو في مجلد Tests/Screenshots
```

> القائمة الكاملة البند-بند موجودة في ملف Excel المرفق بالتسليم: `قائمة_قبول_واختبار_المراحل_0.1-0.5.xlsx`
